# 专班周报草稿生成 Prompt

## 功能说明

此 Prompt 用于汇总全部人员周报和任务完成情况，生成专班周报初稿。

## Prompt 模板

```
请根据以下专班成员的周报分析结果，生成专班周报草稿。

周次：{week_name}

{weekly_reports_summary}

请生成一份简洁的专班周报草稿，包含：
1. 本周总体情况概述（1-2句话）
2. 主要工作成果（3-5个要点）
3. 存在问题和建议（2-3个要点）
4. 下周工作计划（3-5个要点）

要求：
- 语言简洁专业
- 适合向领导汇报
- 突出重点成果
- 控制总字数在500字以内

直接输出周报内容，不要额外说明。
```

## 使用场景

在 `backend/services/llm_service.py` 的 `generate_team_summary` 方法中使用。

## 输出示例

> **专班周报（2026年第19周）**
>
> **一、本周总体情况**
> 本周专班围绕人工智能应用开发重点任务推进，整体进度符合预期。
>
> **二、主要工作成果**
> 1. 完成了任务管理平台的开发上线
> 2. 优化了3个核心场景的Prompt模板
> 3. 完成了首批任务的评价和积分统计
> 4. 建立了周计划-周交付-周评价的初步闭环
>
> **三、存在问题和建议**
> 1. 部分任务存在延期情况，需要加强进度跟踪
> 2. 成果复用价值有待提升，建议建立成果库
>
> **四、下周工作计划**
> 1. 完成成果库功能开发
> 2. 推进第二批任务安排
> 3. 开展大模型应用培训
