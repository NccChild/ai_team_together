# 临时公网隧道指南

使用 localhost.run 将本机后端暴露到公网，方便其他机器访问。

## 前置条件

- 后端已启动（`localhost:8000` 可访问）
- 本机有 SSH 客户端（Windows 10/11 自带 OpenSSH）

## 操作步骤

### 1. 启动后端

```powershell
.venv\Scripts\python.exe -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

确认后端运行：
```powershell
curl http://localhost:8000/
```
返回 `{"name":"AI Team Task Platform","status":"running"}` 即成功。

### 2. 开隧道

**新开一个终端窗口**，执行：

```powershell
ssh -R 80:localhost:8000 nokey@localhost.run
```

看到如下输出即成功：
```
** your connection id is xxxx-xxxx-xxxx
authenticated as anonymous user
https://xxxxxxxxxxxx.lhr.life tunneled with tls termination
```

**`https://xxxxxxxxxxxx.lhr.life`** 就是临时公网地址。

### 3. 其他人访问

浏览器打开 `https://xxxxxxxxxxxx.lhr.life/` 看到 JSON 响应即通。

如果跑前端，需要改 `frontend/.env`：
```env
VITE_API_BASE_URL=https://xxxxxxxxxxxx.lhr.life/api/v1
```
改完后重启 `pnpm dev`。

## 注意事项

- **每次开隧道地址都会变**，需要重新告诉其他人
- 关掉跑隧道的终端窗口，隧道就断了
- 免费版 localhost.run 连接大约 40 分钟后自动断开，重新执行第 2 步即可
- 本机网络环境需要能访问外网（SSH 到 localhost.run）

---

## 方案二：Cloudflare Tunnel（推荐替代方案） 可行

localhost.run 在国内网络环境可能被墙，改用 Cloudflare Tunnel。原理是 cloudflared 只发起 HTTPS 出站连接，通常不会被防火墙拦截。

### 1. 安装 cloudflared

```powershell
winget install cloudflare.cloudflared
```

如果 `winget` 被禁用，手动下载 [cloudflared-windows-amd64.msi](https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.msi) 安装。

### 2. 启动隧道

确保后端已在 8000 端口运行，**新开一个终端窗口**执行：

```powershell
 cloudflared tunnel --url http://localhost:8000 --protocol http2
```

看到如下输出即成功：
```
Your quick Tunnel has been created! Visit it at:
https://xxxxx.trycloudflare.com
```

### 3. 其他人访问

浏览器打开 `https://xxxxx.trycloudflare.com/` 即可。

改前端 `.env` 的话：
```env
VITE_API_BASE_URL=https://xxxxx.trycloudflare.com/api/v1
```

### 注意事项

- 关掉跑隧道的终端窗口，隧道就断了
- 每次启动地址都会变（免费版限制）
- 如果公司网络有 HTTPS 解密（上网行为管理），cloudflared 也可能被拦，此时改用 natapp.cn 或樱花 frp
