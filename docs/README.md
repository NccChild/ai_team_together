# 人工智能专班任务与成果跟踪小工具

本项目用于支撑人工智能专班“周计划、周交付、周评价”管理闭环。

## 目录结构

- frontend：前端工程
- backend：后端工程
- docs：需求说明、开发说明、接口文档
- deploy：部署脚本和部署说明

## 建设原则

- 轻量化开发
- 不做复杂权限
- 不做多级审批
- 优先完成任务管理、成果提交、周评价、统计汇总等核心功能
