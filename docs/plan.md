# 人工智能专班任务与成果跟踪小工具开发计划

## 一、项目定位

本项目用于支撑人工智能专班“周计划、周交付、周评价”管理闭环，面向专班内部约15人使用。系统不建设复杂权限体系，不作为正式绩效考核平台，重点实现任务安排、成果提交、质量评价、贡献统计、周报分析等轻量化功能。

系统建设目标是通过小工具支撑专班形成稳定运行机制，实现“任务有人干、成果有人交、质量有人评、贡献有记录”。

## 十二、MySQL配置要求

后台数据库统一采用 MySQL 8.0，数据库建议命名为：

```sql
CREATE DATABASE IF NOT EXISTS ai_team_task_platform
  DEFAULT CHARACTER SET utf8mb4
  DEFAULT COLLATE utf8mb4_unicode_ci;
```

建议创建独立数据库用户：

```sql
CREATE USER IF NOT EXISTS 'ai_team_user'@'%' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON ai_team_task_platform.* TO 'ai_team_user'@'%';
FLUSH PRIVILEGES;
```

后端配置统一放在：

```text
backend/config.py
```

配置项包括：

```python
APP_NAME = "AI Team Task Platform"
APP_HOST = "0.0.0.0"
APP_PORT = 8000

MYSQL_HOST = "127.0.0.1"
MYSQL_PORT = 3306
MYSQL_USER = "ai_team_user"
MYSQL_PASSWORD = "your_password"
MYSQL_DATABASE = "ai_team_task_platform"

DATABASE_URL = (
    f"mysql+pymysql://{MYSQL_USER}:{MYSQL_PASSWORD}"
    f"@{MYSQL_HOST}:{MYSQL_PORT}/{MYSQL_DATABASE}?charset=utf8mb4"
)
```

## 十七、第一版暂不建设内容

| 暂不建设内容 | 原因 |
|---|---|
| 多级权限 | 当前仅面向专班小范围使用，先降低复杂度 |
| 在线审批 | 任务闭环以负责人评价为主，不做正式流程流转 |
| 附件上传 | 第一阶段采用成果链接方式，减少文件管理复杂度 |
| 单点登录 | 当前为轻量工具，暂不接入统一认证 |
| 消息提醒 | 第一阶段以页面看板和周例会推动为主 |
| 知识库问答 | 后续可基于成果库和周报数据扩展 |
| 自动任务推荐 | 待积累一定任务和人员数据后再扩展 |

## 十八、项目目标

第一版系统以“能用、好用、可持续迭代”为目标，优先实现专班任务管理闭环。系统建成后，应能够支撑每周任务安排、成果提交、质量评价、贡献统计和周报分析，推动专班管理从口头安排转向数据化、可追踪、可评价的运行机制。
